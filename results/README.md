# 已跑完的结果（截至 2026-11-17 10:50）

所有实验都在同一台 RTX 4090 上、种子 2023、不加噪声，用 IB-RFF 作者的 ManyRx 协议（见上一级 README）。
准确率单位为 %。CR：没见过的接收机、第 1–2 天；CRD：没见过的接收机、第 3–4 天。都不用测试接收机的任何数据。

## 1. 方法一：去掉 lm head，换成 10 类分类头（4 折都跑完了）

| 方法 | CR（第 0 / 1 / 2 / 3 折） | CR 平均 | CRD（第 0 / 1 / 2 / 3 折） | CRD 平均 |
|---|---|---|---|---|
| FAN（作者代码，同机同种子） | 91.87 / 84.56 / 91.54 / 88.51 | **89.12** | 89.65 / 86.51 / 90.42 / 82.84 | **87.35** |
| Qwen3.5-0.8B 预训练，全参数微调 | 81.09 / 82.99 / 87.27 / 84.95 | 84.08 | 79.30 / 85.37 / 85.25 / 80.04 | 82.49 |
| Qwen3.5-0.8B 同结构随机初始化 | 71.15 / 70.01 / 72.11 / 73.97 | 71.81 | 63.07 / 71.08 / 69.49 / 66.17 | 67.45 |
| Qwen3.5-4B 预训练，LoRA 秩 16 | 73.08 / 73.70 / 83.37 / 77.15 | 76.82 | 65.91 / 75.07 / 80.22 / 70.47 | 72.91 |

- 4 折都低于 FAN；但比同结构随机初始化高 12–15 个点，说明语言预训练有用。
- 4B（LoRA）比 0.8B（全参数）还差。
- 文件：`qwen_cls_head/`。每个 `qwen_*.json` 里有参数、每轮训练记录、四个测试集的结果（总体、按接收机型号、按接收机和天）和噪声等干扰下的测试；`probs_*.npz` 是每个测试样本的 10 类概率；`qwen_pilot.log` 是运行日志。

## 4. 还没下结论的地方

- 方法二只有第 0 折，第 0 折对 FAN 来说是容易的一折；单折单种子波动 2–5 个点。第 1–3 折正在服务器上跑。
- 频域的提升可能来自"频域表示"本身，不一定是大模型的功劳。对照实验（作者 FAN 改用频域输入，4 折）正在跑。
- GRPO 的提升可能部分只是"多训了几轮、按准确率选模型"，还没做"继续 SFT 同样步数"的对照。
